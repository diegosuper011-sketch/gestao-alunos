# Gestão Acadêmica

Aplicação web para cadastro e acompanhamento de alunos, notas e frequência.

## Instalação
1. Instale Node.js 18+ e PostgreSQL.
2. Crie o banco `gestao_alunos` no PostgreSQL.
3. Copie `.env.example` para `.env` e configure suas credenciais.
4. No terminal, nesta pasta, execute `npm install`.
5. Execute `npm run dev`.
6. Abra http://localhost:3000.

O servidor cria as tabelas automaticamente.
